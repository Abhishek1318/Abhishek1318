### 💼 Featured Enterprise Projects (WNS Global Services)

Here are the key enterprise-scale solutions I contributed to under the **SKENSE** platform at WNS:

#### 1. 📋 Automated Insurance Claims Processing (STP)
*Developed an end-to-end Straight-Through Processing (STP) pipeline for major clients like AFI and Howden.*
- **Objective**: Automate the extraction of structured data from highly unstructured, multi-page insurance claim PDFs and make automated decisions.
- **Tech Stack**: Python, OCR Engines, LLMs, FastAPI, Azure Kubernetes Service (AKS).
- **Key Contributions**:
  - Engineered the document preprocessing and data transformation pipelines.
  - Collaborated on the decision-tree logic that automates claim acceptance or rejection based on extracted metadata.
  - Integrated LLMs to interpret complex, ambiguous clauses within claim documents, increasing overall processing accuracy.
  - Conducted extensive unit and integration testing (SIT, UAT) to ensure production readiness.

#### 2. 🧠 Gen AI-Powered Document Intelligence
*Built advanced Retrieval-Augmented Generation (RAG) and intelligent document parsing applications.*
- **Objective**: Reduce manual reading and summarizing times for complex insurance policies and financial invoices.
- **Tech Stack**: Large Language Models (OpenAI, Hugging Face), RAG architectures, Prompt Engineering, Vector Databases.
- **Key Contributions**:
  - Developed RAG systems that query complex PDFs and return contextually accurate summaries and metadata.
  - Applied advanced prompt engineering techniques to structure model outputs into clean JSON schemas.
  - Reduced manual auditing efforts and document turnaround times significantly.

#### 3. 🚀 Azure-Based Enterprise AI Deployment
*Established the infrastructure and ML lifecycle for deploying high-scale AI services.*
- **Objective**: Containerize and deploy LLM APIs and ML models with enterprise-grade security and reliability.
- **Tech Stack**: Docker, Azure Kubernetes Service (AKS), Azure Event Hubs, Azure Cosmos DB, CI/CD pipelines.
- **Key Contributions**:
  - Containerized FastAPI microservices using Docker and deployed them to AKS.
  - Configured event-driven ingestion pipelines using Azure Event Hubs for real-time document processing.
  - Designed Cosmos DB schemas for low-latency retrieval of processed document metadata.
